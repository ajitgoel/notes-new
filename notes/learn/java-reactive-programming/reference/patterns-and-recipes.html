Reactive Patterns & Recipes

Copy-paste patterns for Empower PMS · Project Reactor 3.x

Error & Fallback

Not-Found → 404
When: repo returns empty Mono, you want a domain error
repo.findById(id)
    .switchIfEmpty(Mono.error(new NotFoundException("Patient", id)));
Primary → Cache Fallback
When: live API fails, fall back to cached value
liveApi.get(key)
    .onErrorResume(ServiceUnavailableException.class,
        ex -> redisCache.get(key));
Retry with Exponential Backoff
When: transient Service Bus / network failure
operation
    .retryWhen(Retry.backoff(3, Duration.ofMillis(200))
        .maxBackoff(Duration.ofSeconds(5))
        .jitter(0.5)
        .filter(ex -> ex instanceof TransientException));
Fire-and-Forget Side Effect
When: publish event but don't fail fill if event fails
rxRepo.save(prescription)
    .flatMap(saved -> eventBus.publish(saved)
        .onErrorResume(ex -> { log.warn("event failed",ex); return Mono.empty(); })
        .thenReturn(saved));

Combining

Parallel Lookups → Combine
When: two independent async calls, need both results
Mono.zip(patientRepo.findById(pid), insuranceSvc.get(pid))
    .map(t -> new FillContext(t.getT1(), t.getT2()));
Mono → Flux (one-to-many)
When: first lookup a parent, then stream children
patientRepo.findById(pid)
    .flatMapMany(p -> rxRepo.findByPatientId(p.getId()));

Threading

Wrap Blocking Legacy JDBC
When: you must call blocking JDBC from a reactive chain
Mono.fromCallable(() -> jdbcRepo.findById(id))
    .subscribeOn(Schedulers.boundedElastic());
Blocking Collection → Flux
When: blocking call returns a List, convert to streaming Flux
Mono.fromCallable(() -> jdbcRepo.findAll())
    .subscribeOn(Schedulers.boundedElastic())
    .flatMapMany(Flux::fromIterable);

Service Bus / Sinks

Push Event from Imperative Code
When: bridging a REST handler push to a reactive Flux publisher
private final Sinks.Many<RxEvent> sink =
    Sinks.many().multicast().onBackpressureBuffer(512);

// Push from anywhere:
sink.tryEmitNext(event);

// Expose as Flux:
@Bean Supplier<Flux<RxEvent>> publishRxEvent() { return sink::asFlux; }
Service Bus Consumer with DLQ
When: processing Service Bus messages reactively with safe error handling
messages.flatMap(
    msg -> process(msg.getPayload())
        .doOnSuccess(v -> receiver.complete(msg))
        .onErrorResume(ex -> {
            log.error("DLQ: {}", msg.getMessageId(), ex);
            receiver.deadLetter(msg, new DeadLetterOptions()
                .setDeadLetterReason(ex.getMessage()));
            return Mono.empty();
        }),
    10 // concurrency
);

Testing

Test Time-Based Retry
When: testing retry/timeout logic without real delays
StepVerifier.withVirtualTime(() -> operationWithRetry)
    .thenAwait(Duration.ofSeconds(30))
    .verifyComplete();
Assert Error Type
When: testing that a domain exception is emitted
StepVerifier.create(svc.fill(inactivePatientId, ndc, qty))
    .verifyError(InactivePatientException.class);
