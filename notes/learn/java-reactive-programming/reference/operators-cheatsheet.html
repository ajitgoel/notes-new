Reactor Core — Operators Cheatsheet

Project Reactor 3.x · Spring Boot 3.x · Empower PMS reference
Transform — Synchronous
.map(fn)1:1 sync transform. fn must NOT block or do I/O.
.cast(Class)Type-cast each item. ClassCastException on mismatch.
.index()Adds a long index to each item → Tuple2(index, T)
.timestamp()Wraps each item with emission timestamp.
Transform — Async (Inner Publisher)
.flatMap(fn)1:N async. Concurrent, unordered. fn returns Mono/Flux.
.flatMap(fn, n)Same, with concurrency cap n.
.concatMap(fn)Sequential, ordered. Waits for inner to complete.
.flatMapSequentialConcurrent fetch, but merge in order.
.flatMapMany(fn)Mono → Flux: fn returns Flux.
.switchMap(fn)Cancels previous inner on new item (like debounce).
Filter
.filter(pred)Pass only items matching predicate.
.filterWhen(fn)Async filter — fn returns Mono<Boolean>.
.take(n)Take first n items, then cancel upstream.
.takeLast(n)Buffer and emit only last n items.
.takeWhile(pred)Take while predicate true, stop at first false.
.skip(n)Skip first n items.
.distinct()De-duplicate by equals/hashCode.
.distinctUntilChangedDrop consecutive duplicates.
Combine
Mono.zip(a,b)Run a & b in parallel, combine when both complete.
Flux.zip(a,b)Pair items by position from two Fluxes.
.zipWith(other)Pair this Flux with another by position.
Flux.merge(a,b)Concurrent: interleave items from both (unordered).
Flux.concat(a,b)Sequential: a completes, then b starts.
Flux.combineLatestEmit whenever either source emits, using latest.
.mergeWith(other)Merge this Flux with another concurrently.
Error Handling
.onErrorReturn(v)Emit fallback value, complete normally.
.onErrorReturn(T,v)Target specific exception type.
.onErrorResume(fn)Switch to fallback publisher. fn returns Mono/Flux.
.onErrorMap(fn)Transform exception type (wrap/translate).
.onErrorComplete()Convert error to normal completion (empty).
.doOnError(fn)Side-effect on error. Error still propagates.
.retry(n)Re-subscribe up to n times on error.
.retryWhen(spec)Retry with backoff, filter, jitter.
Fallback / Switching
.switchIfEmpty(alt)Use alt publisher if this emits nothing.
.defaultIfEmpty(v)Emit v if stream completes empty.
.switchOnFirst(fn)Inspect first item, branch to different Flux.
Side Effects (do*)
.doOnNext(fn)Inspect each item. Does NOT transform.
.doOnComplete(fn)Runs when stream completes normally.
.doOnSubscribe(fn)Runs when subscribed.
.doOnCancel(fn)Runs on cancel (useful for cleanup).
.doOnTerminate(fn)Runs on both complete AND error.
.doFinally(fn)Runs on complete, error, OR cancel.
.log()Log all signals. Dev/debug only.
Aggregation (Flux → Mono)
.collectList()All items into Mono<List<T>>.
.collectMap(fn)Items into Mono<Map<K,T>>.
.reduce(fn)Fold all items to single value.
.count()Mono<Long> of item count.
.last()Emit only the last item.
.next()Take first item as Mono.
.then()Discard items, return Mono<Void> on complete.
.thenReturn(v)Discard items, emit v on complete.
Threading / Scheduling
.subscribeOn(s)Where upstream source executes. First one wins.
.publishOn(s)Switch thread for downstream ops from here.
Schedulers.parallel()CPU-bound, non-blocking. Fixed pool.
Schedulers.boundedElastic()Blocking I/O. Elastic, capped pool.
Backpressure
.limitRate(n)Request n items, refill at 75%.
.onBackpressureBuffer(n)Buffer up to n, then overflow error.
.onBackpressureDrop(fn)Drop excess items, callback on drop.
.onBackpressureLatest()Keep newest item, drop older ones.
.onBackpressureError()OverflowException on overflow. Fail-fast.
Creating Publishers
Mono.just(v)Eager: value captured immediately.
Mono.defer(fn)Lazy: fn called per subscription.
Mono.fromCallable(fn)Wrap blocking/throwing supplier.
Mono.fromRunnable(fn)Wrap side-effecting void action.
Mono.empty()Completes immediately, no item.
Mono.error(ex)Immediately errors.
Flux.fromIterable(c)Wrap any Iterable/Collection.
Flux.range(n,cnt)Emit integers n to n+cnt-1.
Sinks.many().multicast()Hot: push to multiple subscribers.
Testing (reactor-test)
StepVerifier.create(p)Start verifier for publisher p.
.assertNext(fn)Assert next item with assertions fn.
.expectNextCount(n)Expect exactly n items.
.verifyComplete()Assert onComplete(). Terminal.
.verifyError(T)Assert onError of type T. Terminal.
.withVirtualTime()Virtual clock for time-based tests.
.thenAwait(dur)Advance virtual clock by duration.
