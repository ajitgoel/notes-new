Expressions, Functions
& Meta-Arguments

count, for_each, dynamic blocks, conditionals, and the built-in functions that make your HCL DRY and powerful.

🔁 count — Repeat a Resource N Times

count creates N copies of a resource. The count.index meta-value (0-based) lets you differentiate each instance. Use it for simple numeric repetition:

main.tf — countresource "azurerm_resource_group" "env_rgs" {
  count    = 3
  name     = "rg-empower-env-${count.index}"
  location = var.location
}

# Reference the second resource group (index 1)
# azurerm_resource_group.env_rgs[1].name

# More useful: toggle a resource on/off with a boolean variable
resource "azurerm_monitor_diagnostic_setting" "aks_diag" {
  count = var.enable_diagnostics ? 1 : 0
  name  = "aks-diagnostics"
  # ... rest of config
}
count pitfall

If you remove an element from the middle of a count list, Terraform destroys and recreates all resources with a higher index. Use for_each instead whenever the set of instances might change.

🗝️ for_each — Map-Based Repetition

for_each accepts a map or set(string). Each resource instance is keyed by the map key — stable identity, no index shifting. This is the production-grade approach for multi-instance resources:

main.tf — for_each with maplocals {
  # Key = logical name, value = config object
  namespaces = {
    rx-intake      = { env = "prod", tier = "Standard" }
    clinical-review = { env = "prod", tier = "Standard" }
    billing         = { env = "prod", tier = "Premium" }
  }
}

resource "azurerm_servicebus_namespace" "ns" {
  for_each = local.namespaces

  name                = "sb-empower-${each.key}"
  location            = azurerm_resource_group.main.location
  resource_group_name = azurerm_resource_group.main.name
  sku                 = each.value.tier
}

# Reference: azurerm_servicebus_namespace.ns["billing"].id
# Plan output shows: azurerm_servicebus_namespace.ns["billing"]
for_each with set(string)variable "allowed_ip_ranges" {
  type    = set(string)
  default = ["10.0.0.0/16", "172.16.0.0/12"]
}

resource "azurerm_network_security_rule" "allow_vpn" {
  for_each = var.allowed_ip_ranges

  name                       = "allow-${replace(each.value, "/", "-")}"
  source_address_prefix      = each.value
  destination_port_range     = "443"
  # ... rest
}

🔄 Dynamic Blocks

When a block type (not a resource) needs to be repeated — like network_rule inside a Key Vault — use dynamic:

dynamic block patternresource "azurerm_key_vault" "main" {
  name                = "kv-empower-${var.environment}"
  resource_group_name = azurerm_resource_group.main.name
  location            = var.location
  sku_name            = "standard"
  tenant_id           = data.azurerm_client_config.current.tenant_id

  # Dynamically generate one network_acls block per IP range
  dynamic "network_acls" {
    for_each = var.key_vault_ip_rules
    content {
      default_action             = "Deny"
      bypass                     = ["AzureServices"]
      ip_rules                   = [network_acls.value]
    }
  }
}

📐 Essential Built-in Functions

Terraform has 100+ built-in functions. These are the ones you'll use in almost every project:

merge(map1, map2)
Merge maps; right wins on conflict. Essential for tag merging.
concat(list1, list2)
Join two lists into one.
flatten([list])
Collapse nested lists into a single flat list.
toset(list)
Deduplicate a list into a set. Required for for_each.
lookup(map, key, default)
Safe map lookup with fallback. Avoids null errors.
coalesce(a, b, c)
Returns first non-null, non-empty value.
format(fmt, args…)
sprintf-style string formatting.
lower / upper / trim
String transformations. Use lower() for resource names.
jsonencode(value)
Serialize an HCL value to JSON string. IAM policies, etc.
file(path)
Read a local file as a string. Useful for startup scripts.
templatefile(path, vars)
Render a template file with variable substitution.
try(expr, fallback)
Evaluate expr; return fallback if it errors. Null safety.
functions in practice — empower pms contextlocals {
  # Merge base tags with module-specific tags
  all_tags = merge(local.common_tags, { Module = "networking" })

  # Collect all subnet IDs into a flat list
  all_subnet_ids = flatten([
    azurerm_subnet.aks[*].id,
    azurerm_subnet.data[*].id
  ])

  # Safe lookup: override region per env, default to var.location
  effective_location = lookup(var.location_overrides, var.environment, var.location)

  # Build a JSON-encoded policy document for Key Vault access
  kv_policy_json = jsonencode({
    permissions = { secrets = ["get", "list"] }
  })
}

# try() — safe attribute access when resource may not exist
output "acr_login_server" {
  value = try(azurerm_container_registry.main.login_server, "")
}

🔀 For Expressions

Transform or filter collections inline — like map/filter in your Java streams:

for expressionslocals {
  # Transform: extract just the IDs from a map of resources
  subnet_ids = [for s in azurerm_subnet.app : s.id]

  # Filter: only prod namespaces
  prod_namespaces = {
    for k, v in local.namespaces :
    k => v
    if v.env == "prod"
  }

  # Transform map keys to uppercase
  upper_tags = {
    for k, v in var.tags :
    upper(k) => v
  }
}
