💡 How to use this course

Work through lessons in order — each builds on the last. Every lesson ends with a 3–4 question quiz; click answers for immediate feedback.

After finishing all 8, open reference/CHEATSHEET.md as your day-to-day reference while building Empower PMS. Use learning-records/LEARNING-RECORD.md to track your build phases.

Recommended next step after Lesson 8: start the Phase 2 networking module — VNet, AKS subnet, data subnet with service endpoints — then layer in AKS, Key Vault, Service Bus, and SQL one module at a time.
