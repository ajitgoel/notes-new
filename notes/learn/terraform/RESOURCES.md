# Terraform Resources

## Knowledge

- [Terraform Official Documentation](https://developer.hashicorp.com/terraform/docs)
  The authoritative source. Use for: HCL syntax, resource arguments, provider docs, backend config.

- [Terraform Azure Provider Docs](https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs)
  Every `azurerm_*` resource with all arguments and attributes. Use for: any Azure resource block you're writing.

- [Terraform: Up & Running — Yevgeniy Brikman (O'Reilly)](https://www.terraformupandrunning.com/)
  Best practical book. Covers modules, state, workspaces, testing. Use for: module design patterns, remote state, gotchas.

- [Azure Landing Zone Terraform Accelerator](https://github.com/Azure/alz-terraform-accelerator)
  Official Microsoft reference implementation. Use for: enterprise-grade module structure and naming conventions.

- [Terraform Best Practices — Anton Babenko](https://www.terraform-best-practices.com/)
  Community-maintained, opinionated. Use for: naming conventions, file layout, module design.

- [HashiCorp Learn — Terraform Tutorials](https://developer.hashicorp.com/terraform/tutorials)
  Free, hands-on tutorials with real examples. Use for: feature-specific deep dives (workspaces, testing, CDK).

## Wisdom (Communities)

- [r/Terraform](https://www.reddit.com/r/Terraform/)
  Active, practical, good signal-to-noise. Use for: module design questions, debugging plan output, state management war stories.

- [Terraform Discuss Forum](https://discuss.hashicorp.com/c/terraform-core)
  Official HashiCorp forum. Use for: bugs, provider issues, questions that need a definitive answer.

- [CNCF Slack — #terraform channel](https://slack.cncf.io/)
  Use for: infrastructure-as-code professionals, Kubernetes + Terraform patterns.
